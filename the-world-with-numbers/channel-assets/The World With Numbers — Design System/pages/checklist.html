Pre-render checklist

Run through this before kicking off a render. Every fail wastes 40+ minutes of compute. The critic agent automates most of these, but the first three (content, citation, palette sync) must be human-verified.

A

Content & data

4 checks · manual
Every data scene has a real, verifiable citation.
No "Source: internet" placeholders. Full org + year + URL.
LC-2 · VB-5
Numbers have been cross-checked against the primary source.
Secondary aggregators (Statista wrapping another report) don't count — find the original.
Brand · precise
Ranking ordering matches the data, not the narrative.
If you re-order items for storytelling, annotate it — never silently.
VB-3
All dates / units / currencies are normalized and labelled.
"$" is USD nominal unless declared otherwise. State base year for any real-term figure.
Brand · precise
B

Tokens & imports

5 checks · grep
No hex codes in source. grep -rE "#[0-9a-fA-F]{3,6}" src/remotion/scenes returns nothing.
All colors imported from @/remotion/palette.
Colors
No inline fontSize: NN. All via type tokens.
Grep for fontSize:\s*[0-9]. Fail on any hit.
Type · VB-4
All spacing is a multiple of 8px.
14, 18, 22, 30, 42 px values must not appear. Use the --s-* tokens.
LC · 8pt
npm run sync-palette ran after any design-system.json edit.
palette.ts regenerated; commit both.
Contracts
Fonts loaded via loadFonts() before first frame.
Missing call produces silent system-font fallback — visually catastrophic.
Type
C

Visual rules (VB-1..7)

8 checks · critic agent
Every scene reaches ≥ 80% frame utilization.
Excluding OpeningScene + ClosingScene explicit exceptions.
VB-1
Value-to-color mapping is proportional, never binary.
interpolateColors() used for any ranked color.
VB-2
Bars share one baseline scale; no fake normalization.
Corner radius = 0.
VB-3
No text below 20px anywhere in any frame.
Including axis labels, citations, footnotes.
VB-4
Gridlines ≤ 10% opacity; no decorative bars or shapes.
Every visual element serves a data purpose.
VB-5
Every number element has font-variant-numeric: tabular-nums.
VB-4 · Type
Entrances complete by 30% of scene duration.
Stagger totals ≤ 2s. No linear easing.
VB-6
Template name reflects data shape, not topic.

When a check fails

Do not patch at the scene levelIf three scenes fail VB-1, the template is wrong — fix the template once, every scene inherits the fix. Scene-level patches erode the system.
Never disable a critic rule to shipIf the rule is wrong for this specific case, either document a new named exception (like OpeningScene for LC-1) in DESIGN-SYSTEM.md or redesign the scene.
