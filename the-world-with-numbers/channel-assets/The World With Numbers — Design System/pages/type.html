Tabular numerals — mandatory

Every number in the brand is monospaced AND tabular. Non-tabular numbers shift width during counter animations and make ranked lists stagger — instantly signals unprofessional production.

✗ Proportional figures

1,234,567
3,111,111
2,848,000
9,876,543
Digits shift. Right edge jumps.

✓ Tabular figures (required)

1,234,567
3,111,111
2,848,000
9,876,543
Digits aligned. Right edge locked.
/* Required on every number element */
font-family: "Montserrat", sans-serif; /* number elements */
font-feature-settings: "tnum" 1, "lnum" 1;
font-variant-numeric: tabular-nums lining-nums;
