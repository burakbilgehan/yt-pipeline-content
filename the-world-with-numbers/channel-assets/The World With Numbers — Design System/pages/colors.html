The palette, with roles

Seven brand tokens. Two data accents. Max two colors per chart. Sage is structural only. This isn't aesthetic preference — it's the contract that makes every video feel part of the same body of work.

Absolute rules

Max 2 data colors per chartPink + Blue. Never add a third vivid color. If the data has three series, use Pink / Blue / Sage — where Sage is the baseline or reference series, not a peer.
Sage is structuralGrid lines, axis labels, tertiary annotation, reference baselines. Never a primary data series.
No #FFF. Ever.All text uses Warm Cream #F0EDE8. Pure white breaks the dusty-editorial mood.
No gradient text. No gradient backgrounds.Background is solid #2A2A32. No text ever has a gradient fill.
Never hardcode hex in codeImport from src/remotion/palette.ts. Token changes flow: design-system.json → npm run sync-palette → palette.ts.

VB-2 — the chromatic-scale rule

When values represent a spectrum (cheap→expensive, short→long), colors interpolate proportionally. Never binary. A value at 30% of the range gets a color 30% between --negative and --positive. Implementation uses Remotion's interpolateColors().
