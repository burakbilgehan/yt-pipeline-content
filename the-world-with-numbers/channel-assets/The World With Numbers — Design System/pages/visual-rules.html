04 · Visual rules

VB-1 through VB-7

Non-negotiable visual behaviours. Any component that violates them must not pass critic review. These exist because data integrity and viewer trust are indistinguishable in this channel.

VB-1 · Screen utilization

Fill the frame

Content must occupy ≥ 85% of the frame area — target 90%. Viewers watch on phones. Tiny centered content surrounded by padding is unusable at mobile size. (Min raised from 80% to 85% — Burak 2026-04-17.)

VB-2 · Value-to-color mapping

Chromatic scale, never binary

When values sit on a spectrum (low→high, good→bad), colors interpolate proportionally. A value at 30% of the range gets a color 30% between --negative and --positive. Binary coloring lies about magnitude.

VB-3 · Proportional bar sizing

Bars must tell the truth

Bars, progress indicators, and comparative fills must truthfully represent the underlying ratio. No winner-takes-all. No fake normalization that makes 100 and 10 look equally tall.

✓ Proportional duel · A=3, B=5
3 / 85 / 8
✗ Winner-takes-all — FAIL
3 → fake half5 → fake half
Consistent baselineAll bars share the same scale. Largest value = max width. Others proportional.
No fake normalizationIf values are 100 and 10, the visual must show 10:1. Don't each-to-its-own-max.
Animations target truthSpring/interpolate must converge to the mathematically correct final width, not an aesthetic approximation.
Bar corner-radius0 — squared. Rounded bars are banned.
VB-4 · Typography hierarchy

Unambiguous reading order

Every frame must have one focal element. Font sizes establish hierarchy. Hard floor: 20px. See Typography for the full scale.

VB-5 · Data-ink ratio

Maximize signal, minimize decoration

Every visual element must carry information. Decoration competes with data. Gridlines ≤ 10% opacity. Direct labels over legends. Sources always shown.

✓ Subtle gridlines · 8% opacity
✗ Heavy gridlines — FAIL
No empty barsEvery bar must carry data. No decorative bars behind labels.
Direct labellingLabel data points directly. Legends only when direct labelling is impossible.
Source attributionAlways present. Bottom-right, 22px Inter, var(--text-muted).
VB-6 · Animation timing budget

Entrance done in the first 30%

Entrance animations must complete in a duration-aware window: whichever is smaller — 30% of scene duration, or 8 seconds absolute. A 10-second scene shouldn't waste 3 seconds on animation; a 60-second scene shouldn't spend 18 seconds on it either.

entrance_budget = min(scene_duration × 0.30, 8s)

VB-7 · Template genericity

Templates visualize structures, not topics

Templates are content-agnostic. They visualize data shapes — rankings, duels, timelines — not specific subjects.
