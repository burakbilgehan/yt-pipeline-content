What this is

This design-system project is a review surface, not the source of truth. Token values are mirrored from yt-pipeline-content/the-world-with-numbers/channel-assets/design-system.json. Runtime components live in yt-pipeline/src/remotion/. When a value changes here, it must change in the JSON first, then re-sync via npm run sync-palette.

The goal of this mirror: give the storyboard and critic agents a single readable reference so scene-to-scene inconsistency — the problem you flagged — stops happening at authoring time, not at render time.

Scene category defaults

From design-system.json → sceneDefaults. These are the L2/L3/L4 combinations the storyboard agent assigns by default — scenes should override only with justification.

  • herodot-grid + flat + blur-fade-in — hook titles, clean background, single accent element.
  • data-vizdot-grid + glass + blur-fade-in — chart 60–70% of frame, title top-left, source bottom-right.
  • comparisondot-grid + glass + blur-fade-in — side-by-side equal weight, thin sage 1px divider.
  • listdot-grid + flat + blur-fade-in — max 6–8 items, 10-frame stagger, horizontal bars behind values.
  • narrativefilm-grain + none + blur-fade-in — centered key stat or quote, optional 15% bg visual.
  • ctadot-grid + glow + blur-fade-in — minimal; channel + subscribe + accent underline only.

The consistency problem — and how this system solves it

You flagged that scenes with the same logical purpose render inconsistently — some titles drift, bar styles vary, citations land in different corners. The root cause isn't the tokens; it's that the storyboard agent has latitude to reinvent layout per scene. This DS closes that gap in three places:

1 · Scene contracts Page 06 defines absolute anchors for every scene type. Title is always at x=56 / y=56. Citation is always at x=right-56 / y=bottom-56. Bars always have radius 0. Agents reference the contract, not their intuition.
2 · Agent prompt patches Page 07 provides drop-in additions for storyboard.md and critic.md that force catalog lookup, contract verification, and rejection of ad-hoc styling.
3 · Pre-render checklist Page 08 lists the 18 hard-gate checks. Any FAIL blocks handoff. The critic agent runs this against every storyboard before the production agent starts rendering.
